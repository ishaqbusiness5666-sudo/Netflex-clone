# 🎬 Netflix Clone

A fully responsive Netflix Clone built using HTML, CSS, and JavaScript.

This project recreates the Netflix landing page UI with a modern design and responsive layout for all devices.

---

# 🚀 Features

* Fully Responsive Design
* Modern Netflix UI Clone
* Interactive Sections
* Smooth Layout & Styling
* Mobile Friendly
* Clean User Experience

---

# 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
